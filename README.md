# 結構模擬器 — 建築師考試「建築結構」練習工具

在瀏覽器裡自由擺放桿件、支承、載重，自動算出反力、剪力圖、彎矩圖、軸力圖與變形曲線，並附上考試常用的判別式、標準值與解題提示。

**線上使用：<https://06-mtt.github.io/structure-simulator/>**

不需安裝、不需登入，用 Chrome 或 Edge 開啟即可。也可以下載整個儲存庫，雙擊 `index.html` 離線使用。

## 功能

| 主題 | 內容 |
|---|---|
| 梁 | 鉸／滾／固定／導向／彈簧支承、內鉸、集中力、均布／梯形／三角形載重、集中彎矩；SFD、BMD、極值與反曲點、面積法、圖形不連續特徵、常用標準值（PL/4、wL²/8…）、撓度 |
| 剛架與拱 | 斜桿、軸力圖、彎矩圖畫在受拉側、三鉸剛架、三鉸拱、兩鉸拱、纜索；M = M₀ − H·y 對照表；變形曲線依彎矩正負著色與變形判讀 |
| 桁架 | 桁架模式、拉壓著色、零桿三法則逐輪判定、截面法切割線（自由體與取矩建議）、載重上限反推（含尤拉挫屈） |
| 穩定性 | 靜定度判別式、幾何不穩定（反力線平行／共點、三鉸共線）提示、機構模態動畫、結構變更 A/B 比較 |
| 靜不定行為 | 連續梁活載重配置與包絡線、支承沉陷與溫度（均勻／溫差）在靜定與靜不定結構的比較 |
| 小計算器 | 斷面性質與應力、分段軸力桿、柱側向勁度與週期、柱挫屈（`calculators.html`） |
| 練習 | 題庫（以題號命名、匯出／匯入 JSON）、測驗模式（隱藏答案、作答後自動對答） |

## 快速上手

1. 工具列「範例…」先載入幾個範例看看
2. 「新檔」→「桿件」工具點兩下畫桿件 → 支承工具點節點 → 載重工具點桿件
3. 數值在右側「屬性」分頁修改；結果在「結果」分頁
4. 畫好的題目按「存入題庫」，之後開「測驗模式」自我測驗

快速鍵：V 選取、M 桿件、P 集中力、U 分布、C 彎矩、H 內鉸、1–5 支承、S 截面法、F 置中、Delete 刪除、Ctrl+Z／Ctrl+Y 復原／重做。

## 注意

- 單位只是標示，輸入時請自行維持一致（預設 kN、m）
- 題庫與自動儲存存在各自的瀏覽器裡；要分享題目，請用「匯出題庫」把 JSON 檔傳給別人，對方再「匯入題庫」
- `tests.html` 是計算驗證頁（與閉合解比對）
- 本工具為個人讀書用途，計算結果請自行判斷
